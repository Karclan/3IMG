# Friend Smash Design

## Gameplay
- Pressure from below: a constant moving threat from off screen that keeps the player moving up ( similar to the game [[Catherine]] )
- Movement controls 
	- Basic WASD and an Action button for the special ability
	- Constant movement unless impeded by a wall, you then have to pick a direction.
	- You can change direction mid run as long as there is a valid path for you.
- Procedurally generating a level 
	- Will need to create blocks of the maze that can be connected to each other.
		- This will need a clever design so we don't repeat too much and we don't create too many dead ends. 
- Score system
- Special abilities
- Pathing through a maze
- AI control for the non player characters
- Powerups
