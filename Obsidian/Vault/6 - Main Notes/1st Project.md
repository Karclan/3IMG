# 1st Project
The 1st project for us should be something very simple mechanic, asset, and requirements wise. We should aim for a finished application we can send to friends, either as an executable or as an embedded web app (executable will look like a virus to people and web hosting I'm not sure how to do yet).

Castell suggested a Match-3 game. Effectively like Bejewelled, Candy Crush, or similar. We should hold a voice call to chat about what we all want to come out of this project and what aspects we think we should need. We might miss things and that's okay.
